# REST API - Облачное хранилище

## Для неавторизованного пользователя (гостя)

- Авторизация.
- Регистрация.

## Для авторизованного пользователя

- Выход из аккаунта (сброс авторизации).
- Работа с папками:
  - Создание папок.
  - Редактирование папок.
  - Удаление папок.
- Работа с файлами:
  - Загрузка файлов.
  - Редактирование файлов.
  - Удаление файлов.
- Разграничение прав доступа к папкам и файлам.

## Разграничение доступа

- Гость может пользоваться только авторизацией и регистрацией.
- Авторизованный пользователь получает доступ к работе с папками и файлами.
- Функционал авторизованного пользователя должен быть недоступен гостю.
- Доступ к папкам и файлам должен контролироваться с учётом прав пользователя.

Описание проекта можно найти в папке "Документы"
